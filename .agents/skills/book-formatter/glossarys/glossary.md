## 🎲 Conceitos Fundamentais de RPG

| Português (PT-BR) | Inglês (EN) | Definição |
|---|---|---|
| **RPG** | RPG (Role-Playing Game) | Jogo de interpretação de personagens em um mundo narrativo. |
| **Mestre / Mestra** | Game Master (GM) | Responsável por narrar a história, controlar NPCs, cenário e aplicar as regras. |
| **Ficha / Character Sheet** | Character Sheet | Registro do personagem (atributos, perícias, recursos, histórico). |
| **Personagem (PJ)** | Player Character (PC) | Personagem controlado pelo jogador. |
| **Personagem Não Jogador (PNJ)** | Non-Player Character (NPC) | Personagem controlado pelo Mestre. |
| **Campanha** | Campaign | Sequência de aventuras/jornadas narrativas. |
| **Aventura** | Adventure | Experiência única de jogo (sessão ou story). |
| **Cenário** | Setting | Mundo fictício onde a história acontece. |
| **História** | Story | Eventos narrados. |

## 🎲 Mecânicas & Dados

| Português (PT-BR) | Inglês (EN) | Definição |
|---|---|---|
| **Rolagem** | Roll | Ação de testar uma habilidade/comportamento com dados. |
| **Sucesso** | Success | Resultado de teste acima do limite definido. |
| **Falha** | Failure | Resultado de teste abaixo do limite definido. |
| **Crítico** | Critical | Resultado extremo (ex.: falha máxima ou sucesso máximo). |
| **Atributo** | Attribute | Capacidade básica do personagem (Força, Agilidade, Astúcia, Espírito, Vigor). |
| **Perícia** | Skill | Habilidade aprendida e treinada (Atletismo, Furtividade, Conhecimento, etc.). |
| **Salvamento** | Save | Resistência a efeitos (Vontade, Vigor, etc.). |
| **Teste** | Check / Test | Conjunto de atributos/perícias para resolver uma ação. |
