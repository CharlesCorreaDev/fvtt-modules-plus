# Foundry VTT Knowledge Base: Dice Rolling & Chat Formatting

> Source: [https://foundryvtt.com/kb/](https://foundryvtt.com/kb/)

## 1. Dice Syntax
- Basic Rolls: `/roll 1d20 + 5`
- Keep Highest / Lowest: `/roll 4d6kh3`
- Exploding Dice: `/roll 1d10x`
- Reroll: `/roll 1d20r<=2`
- Target Count (Dice Pool): `/roll 6d10cs>=8`

## 2. Roll Visibility
- Public Roll: `/r 1d20` (Visible to everyone)
- GM Roll: `/gmr 1d20` (Visible to GM and roller)
- Blind Roll: `/broll 1d20` (Visible only to GM)
- Self Roll: `/sroll 1d20` (Visible only to roller)
