# Foundry VTT - Canonical Glossary

## 🇺🇸 English
- **Document:** The fundamental database entity (Actor, Item, Scene, JournalEntry, User, RollTable).
- **Embedded Document:** A document stored within a parent document (e.g. ActiveEffect in Actor, Token in Scene).
- **DataModel:** The schema-based data structure definition introduced in v10+ ensuring strict typing and validation.
- **ApplicationV2:** The modern UI framework introduced in v12 providing reactive, modular window interfaces.
- **Canvas:** The PIXI.js WebGL rendering layer handling tokens, lighting, vision, and walls.
- **Compendium:** Read-only database packs stored in LevelDB / NeDB for modular distribution.

---

## 🇧🇷 Português
- **Document (Documento):** A entidade central de banco de dados (Ator, Item, Cena, Diário, Usuário).
- **Embedded Document (Documento Embutido):** Documento contido em um pai (ex: Efeito Ativo dentro de Ator).
- **DataModel:** Modelo de dados com esquema tipado e validação nativa introduzido na v10+.
- **ApplicationV2:** Framework moderno de interfaces de usuário introduzido na versão 12.
- **Canvas (Mesa/Cenário):** Camada de renderização WebGL PIXI.js para iluminação, visão e tokens.
- **Compendium (Compêndio):** Pacotes modulares de dados de leitura para distribuição de itens, magias e monstros.
