Especificação Canônica de Alertas (bc_alert.html) Mantis Elements

Alertas são mensagens contextuais de feedback para ações de usuários. De acordo com as diretrizes do Mantis e a especificação de bc_alert.html, todo alerta deve oferecer contraste suave, bordas arredondadas e ícones representativos:

Alertas com Ícone Vetorial e Botão Descartável
Aviso Primário: Novo componente do sistema foi catalogado.
Sucesso: Banco de dados sincronizado com sucesso.
Atenção: Limite de memória atingiu 82%. Considere otimizar.
Erro Crítico: Falha ao autenticar token JWT na rota de API.
Alerta Expandido com Conteúdo Adicional (Heading + Divisor)
Conformidade WCAG 2.2 AA (Diretriz 3.3.1)

A cor nunca deve ser a única condutora de informação em um alerta de sistema. A presença do ícone e do texto instrucional explícito garante a interpretação imediata por pessoas com daltonismo (Deuteranopia e Protanopia).

A classe .alert-dismissible adiciona o espaçamento à direita para o botão .btn-close.
