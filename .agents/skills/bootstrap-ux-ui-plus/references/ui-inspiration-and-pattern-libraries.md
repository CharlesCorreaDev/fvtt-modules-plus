## 🇺🇸 English

### 🏛️ 1. Interaction Design Patterns & Component Libraries
- **[UI Patterns](https://ui-patterns.com/patterns):** Solved interaction design patterns (Breadcrumbs, Carousels, In-place Editing, Multi-step Wizards). Mandatory check before improvising non-standard components.
- **[UI Design Daily](https://www.uidesigndaily.com/):** Daily open-source UI widgets, responsive cards, and clean enterprise dashboards.
- **[Figma UI Kits Community](https://www.figma.com/pt-br/comunidade/ui-kits):** Industry-standard production kits (shadcn, Material 3, Bootstrap 5 UI Kit). Reference for auto-layout and component tokenization.
- **[UI Skills](https://www.ui-skills.com/):** Microinteractions and visual refinement drills.

### 🌟 2. Aesthetic Benchmarking & Visual Portals
- **[Awwwards UI Design](https://www.awwwards.com/websites/ui-design/):** Award-winning digital products showcasing expressive typography (`Google Sans Flex`) and GPU motion.
- **[Dribbble UI Design](https://dribbble.com/tags/ui-design):** SaaS dashboards, crisp light theme data tables, and minimal mobile layouts.
- **[Lucas Batista / Medium (19 Portals)](https://medium.com/@lucas_batista/19-sites-para-inspira%C3%A7%C3%B5es-de-ui-design-8955e0796ad2):** Essential curated hubs (Mobbin, Land-book, Page Flows) for full customer journeys.
- **[Brasil UX Design (Hub Guide)](https://brasil.uxdesign.cc/ui-design-guia-de-sites-para-te-ajudar-a-montar-interfaces-2782c31b6560):** Regionalized tools and UI resource directory for Latin America.
- **[Pinterest UX/UI Curation](https://br.pinterest.com/fflorentino/ux-ui/):** Visual boards for analytical dashboards and dense grid structuring.

### 🛠️ 3. Prototyping & Collaboration Tooling
- **[Uizard](https://uizard.io/templates/):** Rapid AI wireframes that can be translated directly into semantic Bootstrap 5.3 markup.
- **[Pixso](https://pixso.net/):** Collaborative UI platform with CSS Flexbox/Grid token workflows.
- **[Canva Whiteboard](https://www.canva.com/online-whiteboard/ui-design-tool/):** Visual customer journey mapping and structural wireframes.
- **[Blush Design](https://blush.design/blog/post/guide-ui-design):** Modular, customizable vector illustrations with accessible image descriptions.
- **[Maze](https://maze.co/collections/ux-ui-design/ui-design/):** Remote user testing, heatmaps, and quantitative usability metrics.

## 🛠️ 3. Ferramentas de Prototipagem & Whiteboard (Figma, Uizard, Pixso, Canva, Blush)

| Ferramenta | Utilidade no Fluxo de Desenvolvimento | Integração na Skill |
| :--- | :--- | :--- |
| **[Uizard](https://uizard.io/templates/)** | Geração e wireframes rápidos de IA para interfaces e dashboards. | O agente pode traduzir wireframes do Uizard diretamente para código Bootstrap 5.3 limpo e semântico. |
| **[Pixso](https://pixso.net/)** | Plataforma colaborativa de UI design e design system compatível com Figma. | Referência para arquitetura de tokens e auto-layout transpostos para CSS Flexbox e Grid. |

| **[Blush Design](https://blush.design/blog/post/guide-ui-design)** | Ilustrações vetoriais modulares criadas por artistas globais. | Diretrizes para incorporar ilustrações acessíveis com `alt` descritivo sem poluir a interface. |
| **[Maze](https://maze.co/collections/ux-ui-design/ui-design/)** | Testes remotos com usuários, mapas de calor e testes de usabilidade quantitativos. | Critérios para validação de fluxos e taxas de sucesso de tarefas (*Task Success Rate*). |
