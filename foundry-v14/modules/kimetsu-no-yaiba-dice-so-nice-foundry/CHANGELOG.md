# 📜 CHANGELOG - Kimetsu no Yaiba Dice Theme for Dice So Nice

Todas as alterações deste módulo estão documentadas neste arquivo com suporte bilíngue.

---

## [1.0.0.1] - 2026-10-25

### 🇧🇷 Português (Brasil)
- **Novos Temas de Dados**: Adicionados 2 novos conjuntos visuais de dados 3D:
  - 🌊 **Dark Blue Theme (Respiração da Água)**: Inspirado em Tomioka com texturas azuis profundas e números ciano brilhantes.
  - 🍃 **Dark Green Theme (Haori do Caçador)**: Inspirado no padrão xadrez verde de Tanjiro com acabamento metálico.
- **Centralização do Repositório**: Migração oficial para o repositório central `fvtt-modules-plus`.
- **Identidade Visual**: Adicionada imagem de capa (cover) e galeria de prévias dos dados 3D no `README.md`.
- **Tipografia Ajustada**: Correção da associação da fonte `Blood Crow` em `@font-face` garantindo renderização consistente no DsN.
- **Refatoração do Código**: Limpeza no registro das texturas e paletas do *Dice So Nice!*, tornando o carregamento mais leve e modular.
- **Automação de CI/CD**: Adicionado workflow do GitHub Actions com publicação automática na Package Release API do Foundry VTT.

### 🇺🇸 English
- **New Dice Themes**: Added 2 brand-new 3D dice styles:
  - 🌊 **Dark Blue Theme (Water Breathing)**: Inspired by Giyuu Tomioka with deep blue hues and vivid cyan numerals.
  - 🍃 **Dark Green Theme (Hunter's Haori)**: Inspired by Tanjiro Kamado's iconic green-black check pattern.
- **Repository Migration**: Officially migrated to the central `fvtt-modules-plus` repository.
- **Visual Showcase**: Added header cover and full 3D dice previews in `README.md`.
- **Typography Fix**: Aligned `Blood Crow` font `@font-face` declaration for proper 3D rendering in Dice So Nice.
- **Code Refactoring**: Streamlined Dice So Nice texture and colorset registration into a cleaner, modular structure.
- **CI/CD Automation**: GitHub Actions workflow added with automated Foundry VTT Package Release API integration.

## [1.0.0] - 2026-10-25

### 🇧🇷 Português (Brasil)
- **Lançamento Inicial**: Tema de dados 3D customizado inspirado em *Kimetsu no Yaiba (Demon Slayer)* para o Foundry VTT.
- **3 Variações Visuais**:
  - 🎴 *White Theme (Respiração & Pureza)*
  - ⚔️ *Demon Slayer Red (Chamas & Lâminas Nichirin)*
  - 🌙 *Dark Theme (Noite dos Demônios)*
- **Compatibilidade**: Verificado para Foundry VTT v10 a v14 com integração nativa ao *Dice So Nice!*.

### 🇺🇸 English
- **Initial Release**: Custom 3D dice theme inspired by *Kimetsu no Yaiba (Demon Slayer)* for Foundry VTT.
- **3 Visual Styles**:
  - 🎴 *White Theme (Breathing & Purity)*
  - ⚔️ *Demon Slayer Red (Flames & Nichirin Blades)*
  - 🌙 *Dark Theme (Night of Demons)*
- **Compatibility**: Verified for Foundry VTT v10 through v14, requiring *Dice So Nice!*.
